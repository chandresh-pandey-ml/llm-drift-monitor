Behavioral drift, out of the blue.

Versioned canary prompts run against the target model. Responses are scored on length, validity, and embeddings — KS, two-proportion z, and MMD tests, Benjamini–Hochberg corrected at α = 0.05. Drift is a signal for investigation, not a verdict.

What the tests look at

  • KS — response length distribution, canary vs. baseline
  • Z — two-proportion test on invalid-response rate
  • MMD — RBF-kernel divergence on response embeddings

API

the UI is a thin layer — everything is at these routes
  • GET /healthDB + adapter state
  • POST /runsstart a probe + detection cycle
  • GET /runsstored probe history
  • GET /drift/latestmost recent verdict
  • GET /drift/resultsfull test-result log
  • GET /alertsalert history

Source, experiments, and evaluation at github.com/chandresh-pandey-ml/llm-drift-monitor. Demo runs on a deterministic fake adapter (no external API keys). Free-tier instance sleeps after ~15 min idle; the first request takes up to a minute while it wakes.
