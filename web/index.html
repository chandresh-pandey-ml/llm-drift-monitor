Is the model changing?

Every cycle sends the same set of canary prompts to the target model and compares the new responses against the recorded baseline. Responses are scored on length, validity, and semantic content. Three statistical tests look for differences; significant ones are flagged as alerts for human review.

Each run records 10 responses. Statistical tests begin once 60 responses are stored.

Detector reference

  • Length (KS test): compares the distribution of response lengths.
  • Empty (z test): tracks the rate of malformed or refused responses.
  • Meaning (MMD test): compares response embeddings to detect semantic drift.
