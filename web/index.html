Is the model changing?

Each check sends the same test prompts to the target model and compares the new answers with the answers saved earlier. Three small tests look for changes in how long the answers are, how often they come back empty, and what they mean overall. When something changes, the page says so, and a person decides what it means.

Adds 10 new test prompts. The stats need 60 saved answers (about 6 checks) before the tests can run.

What the three tests do

  • Length is the letters-per-answer test. It asks whether answers got noticeably longer or shorter.
  • Empty is the share of unhelpful answers. A jump usually means the model started refusing or breaking.
  • Meaning is the text embedding test. It catches answers that drifted in topic or tone even when the looks are similar.

You do not need this page

the service is also a plain JSON API. Try any of these in a browser.
  • GET /healthis the service up
  • GET /drift/latestthe most recent outcome
  • GET /drift/resultsthe full result log
  • GET /alertssaved alert history
  • GET /runsstored answers, page by page
  • GET /statsexact counts
  • POST /runsstart a new check

Source and the full write up are in the GitHub repo. The demo runs a scripted fake model so no real provider is ever called. This is a free hosting plan, so the page goes to sleep when nobody visits. If a load feels slow, wait about a minute and refresh.
